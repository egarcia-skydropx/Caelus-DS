Logos de las plataformas que usan Caelus, exportados en SVG desde la página Logos del archivo Foundations / Tokens (Caelus), en tamaño default.

- `skydropx-logo.svg`: logotipo completo sobre fondo claro. El isotipo lleva el gradiente verde → azul → violeta (#31C28B, #3F81F6, #7B3FF1) y el texto va en #0E005E.
- `skydropx-logo-invertido.svg`: misma marca con el texto en blanco. Úsalo solo sobre fondos oscuros, `core-primary-900` o `shiphub-surface-default-dark`.
- `skydropx-isotipo.svg` / `skydropx-isotipo-invertido.svg`: solo el símbolo, para avatares, favicons o espacios cuadrados.
- `soloenvios-logo.svg`, `soloenvios-logo-invertido.svg`, `soloenvios-isotipo.svg`: marca Soloenvíos (azul #1227E2 y amarillo #FFCD05).
- `shipkraken-logo.svg`, `prontoenvios-logo.svg`, `envios-internacionales-logo.svg`, `myshiphub-logo.svg`: logos completos de esas plataformas, versión para fondo claro.

Todos son multicolor: no se pueden recolorear con CSS (`<img>` no hereda `currentColor`). Respeta un margen libre de al menos la altura de la “x” del texto alrededor del logo, y no lo estires ni lo rotes.
